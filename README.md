## 🇧🇷 Sobre mim

Trabalho com software há **18 anos**, e a trajetória não foi uma linha reta de desenvolvimento: passou por **dados**, por **produto** e por **plataforma**. Cada etapa deixou uma coisa que uso até hoje.

Comecei em 2008 fazendo **relatórios** para um sistema comercial — views, procedures e triggers em SQL Server expostos no Report Builder. Foi ali que aprendi a **modelar dado antes de exibir dado**. Depois entrei no desenvolvimento do próprio ERP, em Visual Basic: um produto parametrizado que atendia de farmácia a loja de roupas, o que me obrigou cedo a pensar em **generalização em vez de solução pontual**.

Na **Gvinci**, plataforma low-code da qual sou sócio, o trabalho teve duas frentes: construir com a ferramenta (configurar o projeto até o código gerado chegar no resultado desejado, estruturar o banco relacional, criar os temas) e **popularizar a plataforma** — treinamentos, workshops e cursos pelo canal no YouTube, que saiu de **400 para 5 mil inscritos**. Ensinar a ferramenta me obrigou a entendê-la melhor do que construir com ela.

Nos últimos três anos voltei a colocar a mão em código web por conta própria: **React, TypeScript, Node.js, PostgreSQL, Supabase**. Quando tenho uma ideia, construo — às vezes para aprender, às vezes para resolver algo do meu próprio trabalho.

> 💡 Quem passou anos configurando um gerador de código para chegar no resultado certo já conhece o problema que um agente de IA apresenta: **o resultado depende inteiramente da precisão do que foi pedido.**

## About me

I have been building software for **18 years**, and the path was never a straight line: it went through **data**, **product** and **platform**. Each stage left something I still use today.

I started in 2008 writing **reports** for a commercial system — views, procedures and triggers in SQL Server surfaced through Report Builder. That is where I learned to **model data before displaying data**. Later I moved into the ERP itself, in Visual Basic: a parameterized product serving anything from pharmacies to clothing stores, which forced me early on to think in terms of **generalization instead of one-off fixes**.

At **Gvinci**, the low-code platform I co-own, the work had two fronts: building with the tool (configuring projects until the generated code reached the intended result, structuring the relational database, creating the themes) and **growing its adoption** — training, workshops and courses on the YouTube channel, which went from **400 to 5,000 subscribers**. Teaching the tool forced me to understand it better than building with it did.

Over the last three years I went back to hands-on web development on my own: **React, TypeScript, Node.js, PostgreSQL, Supabase**. When I have an idea, I build it — sometimes to learn, sometimes to solve something in my own work.

> 💡 Anyone who spent years configuring a code generator to reach the right result already knows the problem an AI agent presents: **the output depends entirely on the precision of what was asked.**

Day to day, I work with agent-assisted development inside a **specification → implementation → verification** flow, rather than improvised generated code.
